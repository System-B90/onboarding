# CLAUDE.md — onboarding

Org-wide conventions (repo list, Hive-org boundary, package scopes, git workflow, commit
format, CI secrets) live in
[System-B90/.github CLAUDE.md](https://github.com/System-B90/.github/blob/main/CLAUDE.md).
This file covers what's specific to onboarding.

## What onboarding is

The shared guided-tour and help-panel engine, published as
`@system-b90/onboarding` to GitHub Packages. Consumed by bluz (and any app that
wants tours). Extracted from bluz's `ui/src/components/onboarding/`.

## The one rule

Nothing here may know about a host app. No domain concepts, no routes, no copy
in the component tree — every string the engine renders arrives through
`labels`, and every tour/topic arrives through `useTour` / `useHelpTopics` from
the app that owns that screen.

Imports are limited to `react` and `@mui/*`, all peer dependencies. Adding a
runtime dependency is a deliberate decision, not a convenience.

## Languages

`src/labels/en.ts` and `src/labels/he.ts` ship the two tables, each behind its
own package subpath (`/en`, `/he`). Re-word individual strings with
`withLabelOverrides(HE_LABELS, { … })` rather than restating a table.

## Imports

Internal imports use the `@/*` alias (mirroring bluz), enforced by
`no-restricted-imports`. `npm run build` runs `tsc-alias` after `tsc` to rewrite
those specifiers to relative paths in `dist/` — without it the published package
would not resolve. Keep the `.js` extension on every internal specifier; the
package is ESM.

## The model

Anchor → Step → Tour → Topic. See `README.md` for the full breakdown (also
mirrored from bluz's `components/onboarding/README.md`).

## Docs

Prose lives in `docs/` (mkdocs-material). `docs/api/` is generated by TypeDoc
from TSDoc comments in `src/` and is gitignored — never hand-edit it.

## Git

Commit format: `Vibe-<PastTenseVerb> <description>` (e.g. `Vibe-Fixed`, `Vibe-Added`). No
`feat:`/`fix:`/`chore:` prefixes. Never commit directly to `main`/`master` — feature
branch + PR. Bump the package version deliberately before publishing — consumers pin
exact versions.
